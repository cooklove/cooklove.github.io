# CookAmore

La cucina che unisce. Sito ufficiale: https://cooklove.github.io/

Ricettario pubblico in sviluppo: 1000 ricette, 50 per ognuna delle venti regioni italiane, con ricerca, filtri, dosi ricalcolabili, lista della spesa e link condivisibili.

Le schede comprendono piatti tradizionali e proposte casalinghe ispirate ai prodotti regionali. Sono bozze originali assistite, con revisione assistita, da collaudare in cucina. Le 1000 copertine presenti sono immagini illustrative generate con AI per CookAmore. Non sono fotografie documentali dei piatti. Le calorie disponibili sono stime basate sugli ingredienti con fonti USDA/Anses e conversioni dichiarate; per ricette con dati insufficienti la stima resta assente.
